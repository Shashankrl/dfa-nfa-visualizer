# DFA NFA Visualizer

A web-based tool to visualize and experiment with Deterministic Finite Automata (DFA) and Nondeterministic Finite Automata (NFA).

## Features

- Create and edit states and transitions.
- Visualize DFA and NFA graphs.
- (Planned) Simulation and testing.

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm start`
